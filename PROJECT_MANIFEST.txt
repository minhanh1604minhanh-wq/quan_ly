v1.1.0
- Login changed from password-only to username + password.
- Added roles: master (Quản lý chính) and manager (Quản lý).
- Master can create managers, reset manager passwords, revoke/restore manager access.
- Every account can change its own password.
- Passwords are hashed with Node.js scrypt before database storage.
- Session tokens include session_version; password reset/revoke invalidates old sessions.
- Added admin audit log table.
- Preserved dashboard, analytics, character management, AI restrictions, event ingestion and no-Google-Sheets architecture.
